# Decision records

One file per decision that changes the data model, the pipeline, or the rules in
`docs/conception.md`. Number them in order; never renumber or delete. When a decision is
replaced, add a new record and set the old one's status to `Superseded by NNNN`.

Template:

```markdown
# NNNN. Title

Status: Accepted | Superseded by NNNN
Date: YYYY-MM-DD

## Context

## Decision

## Consequences
```
